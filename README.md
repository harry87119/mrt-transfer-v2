# 捷運轉乘來得及嗎

手機用的小網頁：選現在位置和終點站，自動找路線（直達、轉一次或轉兩次），判斷下一班車能接上哪班轉乘車。涵蓋台北捷運、環狀線、三鶯線與機場捷運。

網址：https://harry87119.github.io/mrt-transfer-v2/

> **非官方服務。** 本網頁與台北大眾捷運公司、新北大眾捷運公司、桃園大眾捷運公司、交通部均無關。所有時間依公開資料推算，僅供參考，實際以現場與各捷運公司公告為準。

## 使用方式
到 [TDX 運輸資料流通服務](https://tdx.transportdata.tw/) 註冊，取得 Client Id 與 Client Secret，貼在頁面的「TDX 金鑰設定」。金鑰只存在你自己瀏覽器的 localStorage，不會進到這個 repo。

## 資料來源與授權

| 資料 | 來源 | 授權／條件 | 在本專案的用途 |
|---|---|---|---|
| 路線、時刻表、進站訊號、轉乘時間、站間行駛時間、班距、首末班車、營運通阻 | 資料介接「交通部TDX平臺」 | [政府資料開放授權條款－第1版](https://data.gov.tw/license)，須顯名 | 推算到站與轉乘 |
| 政府行政機關辦公日曆表 | 行政院人事行政總處（[data.gov.tw 資料集 14718](https://data.gov.tw/dataset/14718)） | 政府資料開放授權條款－第1版，須顯名 | 自動判斷國定假日用假日班表 |
| 機場捷運各站時刻表的車種（直達／普通等） | [桃園大眾捷運股份有限公司官網時刻表](https://www.tymetro.com.tw/tymetro-new/tw/_pages/travel-guide/timetable.php) | 網站內容版權屬桃園大眾捷運股份有限公司 | 只擷取每班車的發車時間與車種，用來判斷是否停靠 |
| 部分站的轉乘步行時間 | repo 作者本人實測 | — | 標示為「你實測」 |
| 其餘轉乘步行時間、下車與停站秒數 | 作者預估 | — | 畫面一律標示「預估」 |

關於機場捷運官網資料：
- 依該網站 robots.txt，`/tymetro-new/tw/_pages/` 允許存取。
- 每天只抓一次（22 站 × 今天與明天），每次請求間隔約 1 秒。
- 只保存班次時間與車種這類事實資料，不保存網頁文字或圖片。
- 權利人如不同意此用法，請開 issue 告知，會立即移除 `data/tymc.json` 並停止抓取。

## 每日資料更新
`.github/workflows/update-data.yml` 每天 03:40（台灣時間）執行 `scripts/update_data.py`，把上述資料存到 `data/`，網頁優先讀這些檔案。詳見 [data/README.md](data/README.md)。

## 已知限制
- 台北捷運在 TDX 的即時看板只提供「進站中」的列車，沒有幾分鐘後到站的倒數，所以其他班次依時刻表推算，實際可能差 30 秒以上。
- 「進站中」是列車進站前幾秒出現，目前沒有官方資料，程式當作 0 秒。
