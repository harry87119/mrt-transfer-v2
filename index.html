TDX 金鑰設定

  1. 到 tdx.transportdata.tw 免費註冊會員。
  2. 在「會員中心 → 資料服務 → API 金鑰」取得 Client Id 與 Client Secret。
  3. 貼在下面按「儲存」。金鑰只存在這支手機的瀏覽器，不會傳到別的地方（只會拿去跟 TDX 換通行憑證）。
個人設定

你的預設路線、各線預設站和實測轉乘時間只存在這支手機的瀏覽器，不在公開的程式碼裡。換手機時，用下面的按鈕複製設定連結，在新手機打開一次即可。從主畫面圖示開啟時，資料跟 Safari 是分開存的，請把設定連結貼到下面匯入。

怎麼算的

台北捷運在 TDX 開放資料只提供「進站中」的即時訊號，沒有幾分鐘後到站的倒數，所以其他班次是用站別時刻表推算。看到「進站中」時會以那一刻為準。

預估下車要 15 秒，要轉的那班車停站約 15 秒才關門（這兩個數字不是官方資料）。餘裕 =（轉乘車到站 + 停站）−（我的車到站 + 下車 + 走路）。標籤顯示走到月台後要等多久：不到 1 分鐘紅色，1 到 3 分鐘黃色，3 分鐘以上綠色；接不到的標灰色。

行駛時間優先比對下一站的時刻表，其次用 TDX 站間行駛時間，都沒有才用每站 2 分鐘預估。選路線時的候車時間用 TDX 班距的一半，沒有班距資料時預估 3 分鐘。機捷直達車用「下一站的時刻表有沒有這班車」判斷，比對不到時才用終點站推定，畫面會標「預估」。

機捷每班車是直達還是普通，用桃園捷運官網時刻表；國定假日用行政院人事行政總處的辦公日曆。這兩項和 TDX 的固定資料由 GitHub 每天凌晨自動更新。

資料介接「交通部TDX平臺」，依政府資料開放授權條款第 1 版使用。國定假日資料來自行政院人事行政總處辦公日曆表；機捷車種來自桃園大眾捷運公司官網時刻表。

本網頁為個人製作的非官方工具，與各捷運公司及交通部無關。時間皆為推算，僅供參考，請以現場與官方公告為準。凡不是官方資料的數字都會標「預估」或「你實測」。
